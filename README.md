Movie-Recommender-SystemThis repository contains assignments and practice files implemented throughout the course. The project culminates in a Deep Learning-based Movie Recommender System.Course ProgressWeek-0: Python FoundationsOur basic Python knowledge was refreshed with curated video lectures covering data structures, loops, and functional programming to prepare for the mathematical implementation of Machine Learning algorithms.Week-1: Regression and OptimizationIntroduction to the core mathematical foundations of Supervised Learning.Linear Regression: Implemented models to predict continuous values using basic libraries.Cost Function: Learned to quantify model error using the Squared Error cost function.Gradient Descent: Implemented the optimization algorithm that iteratively minimizes the cost function to find the global minimum.Logistic Regression: Transitioned to classification tasks, utilizing the Sigmoid function to map predictions to probabilities.Tools: Coded primarily in Python and NumPy, with Matplotlib utilized to visualize the "soup bowl" convex shape of cost functions.Week-2: Neural Networks and Model HealthExploration of complex architectures and techniques to ensure model generalization.Neural Networks: Introduced the concept of neurons and layers. Implemented multi-layer perceptrons using TensorFlow and Keras.Activations: Explored ReLU and Softmax activations for hidden and output layers.Overfitting & Underfitting: Studied the Bias-Variance tradeoff. Learned how extra features can cause high variance (overfitting).Regularization: Implemented L2 Regularization to penalize large weights and prevent overfitting, while balancing the risk of underfitting.Assignment: Built a multiclass classification model to recognize handwritten digits (MNIST dataset). The model achieved high accuracy through optimized weights and biases.Week-3: Advanced Recommender Systems (Final Project)The final week focused on building a sophisticated Movie Recommender System using two distinct Deep Learning approaches:1. Collaborative FilteringImplemented a system that predicts user ratings based on the similarity between users and items.Matrix Factorization: Simultaneously learned user parameters ($w, b$) and movie features ($x$).Custom Training Loop: Utilized tf.GradientTape for a more granular implementation of the learning process.2. Content-Based FilteringBuilt a "Two-Tower" Neural Network to recommend movies based on specific content metadata and user preferences.Feature Engineering: Processed movie genres (one-hot encoding), release years, and user ratings to create rich feature vectors.Embedding Vectors: The model generates high-dimensional vectors for both users and movies; the dot product of these vectors predicts the user's likelihood of liking a movie.Item-to-Item Similarity: Used squared distance measures to recommend movies similar to those a user has already enjoyed.Technical StackLanguages: PythonLibraries: NumPy, Pandas, Matplotlib, Scikit-Learn, TensorFlow, Keras.
